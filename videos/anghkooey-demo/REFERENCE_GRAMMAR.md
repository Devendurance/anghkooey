# Transferable grammar

- Hook: a recognisable problem beside actual product context.
- Spine: problem, intent, live action, outcome, changed intent, contrast, evidence, boundaries.
- Reveal logic: engineering and limitations follow visible results.
- Rhythm: longer 6-15s proof passages, short 2-4s connecting beats. No artificial shot-count match.
- Hierarchy: one primary interface region. Large editorial phrases announce meaning, never imitate product messages.
- UI choreography: retain real click/scroll, then crop toward the result. An interface remains the subject after its entrance.
- Motion: restrained push-ins, readable panning, moving cursor. No aggressive spin, elastic overshoot, or glitch.
- Transitions: straight cuts between ideas, soft camera movement within ideas.
- Density: dense output earns a longer hold. Breathing room returns with the outcome summary.
- Captions: phrase-level bottom placement, strong contrast. Anghkooey uses clean Satoshi instead of the reference's italic stroke identity.
- Audio: cadence cannot be measured from image-only review. Target music is quiet and original, edits follow final VO word timing rather than guessed reference beats.
- Proof: same product, real outcomes, visible refusal where evidence is insufficient.
- Ending: practical outcome and honest boundaries before brand resolution.
- Do not transfer: AfterHours identity, peach/blue gradient, purple browser chrome, orange UI, exact copy, soundtrack, financial numbers, wallet storyline.
