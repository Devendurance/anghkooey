# Evidence and limitations

- iMessage source contains both distinct earlier and later states. Earlier question concerns a named traveller. Later question concerns the user's own preferences. This is not an identical-query controlled experiment.
- iMessage recalls quiet hotels and natural light only. Busy-road preference is in Telegram, but sleep reason is absent from the supplied messaging evidence.
- A current separate guest Web save failed. Its answer had no matched memory sources. No current Web save/recall success is shown or asserted.
- Confirmed receipt/correction visuals come from genuine prior local captures and associated DOM/test records, with different preferences and a separate identity.
- Source audio not auditioned. It is removed from the final mix. Final narration is generated ElevenLabs, with returned character timings.
- Desktop Telegram contact lists are excluded. Fixed contact headers are masked. All Web code-value frames are excluded. Original sources remain private and unmodified.
- No subagent API exists in this harness. Independent capture, voice, media processing and original score generation ran concurrently.
